# HireGen AI

## Overview
HireGen AI is an AI-powered recruitment platform that enables recruiters to create, optimize, validate, and manage professional job descriptions using AI.

## Features
- JWT Authentication
- Job Management (Create, Read, Update, Delete)
- AI Job Description Generator
- AI Publish Assistant
- AI Job Description Validator
- Responsive React Frontend
- FastAPI Backend
- OpenRouter AI Integration

## Tech Stack
### Frontend
- React
- Vite
- Axios

### Backend
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication

### AI
- OpenRouter API

## Local Setup

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
